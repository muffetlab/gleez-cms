## [1.3.0](https://github.com/muffetlab/gleez-cms/compare/v1.2.0...v1.3.0) (2026-08-20)

### ⚠ BREAKING CHANGES

* **gleez:** All public table drag APIs including data-toggle attribute and jQuery plugin have been renamed from tabledrag to tableDrag.
* **system:** existing cookies will no longer be valid as the cookie salt calculation no longer includes the user agent
* **gleez:** external code calling fulltree() or accessing $model->fulltree on MPTT ORM instances will break
* **gleez:** Meta::tags no longer accepts the $attrs parameter, and conditional tag attributes are no longer supported
* **gleez:** public CSS class `.fileupload` has been renamed to `.file-upload`, jQuery plugin `$.fn.fileupload` is now `$.fn.fileUpload`, and all related data attributes, event names, and selectors have been updated to use the new naming convention. External code relying on the old API will break
* public Post::dcache method has been renamed to Post::dynamicCache; external code relying on the old method name will break
* **gleez:** public static method Shortcode::parse_atts() has been renamed to parseAttrs(), breaking external code that invokes the old method name.
* **gleez:** rename gdatatable plugin to gDataTable
* **gleez:** standardize ajaxform plugin naming and casing conventions
* **gleez:** Text::htmlcorrector has been renamed to Text::htmlCorrector
* **gleez:** the public Post::$ftags property has been renamed to Post::$formTags, and all ftags form input/POST references have been updated to form_tags. External code using $post->ftags or submitting ftags form data will break.
* **user:** the public static User::belongsto method has been renamed to User::belongsTo, which breaks any code that invokes the original method name.
